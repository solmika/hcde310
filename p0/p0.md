## Resource 1: Open-Meteo -- Weather Forecast API

**What it provides** (1–2 sentences):
Open-Meteo provides a free historical weather forecast API from 1940.

**Docs link:**
https://open-meteo.com/en/docs

**Access:** API key needed? Rate limits? Cost? (write "none" if none)
No API key is needed, and it is free, but it does have a rate limit -- 5,000 call per hour and 10,000 der day.

**Sample response** (trim it to a few fields; paste the URL you called too):
